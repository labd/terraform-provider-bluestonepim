## v1.0.0 - 2026-10-25
### Added
* Add `bluestonepim_column_attribute_definition`, `bluestonepim_matrix_attribute_definition`, `bluestonepim_dictionary_attribute_definition`, `bluestonepim_dictionary_attribute_value` and `bluestonepim_compound_attribute_definition` resources
* Add `bluestonepim_attribute_group` resource
* Add `value`, `propagate` and `locked` to `bluestonepim_category_attribute`, and add `bluestonepim_category_column_attribute`, `bluestonepim_category_matrix_attribute`, `bluestonepim_category_dictionary_attribute` and `bluestonepim_category_compound_attribute` for the other attribute definition types
* Add `bluestonepim_category_context` resource to set the name and description of a category for a specific context
* Validate at plan time that the `restrictions` and `content_type` of a `bluestonepim_attribute_definition` are supported by its `data_type`, for example `restrictions.text.pattern` only for `pattern`
* Add `bluestonepim_attribute_group_order` and `bluestonepim_attribute_group_definition_order` to manage the order of attribute groups and of the definitions in a group, and `order_by_name` on `bluestonepim_attribute_group`. Changing the `number` of a group is now an in-place update instead of a replace
* Add `bluestonepim_relation` resource for product relation types. A relation that is used by product connections is only deleted with `force_destroy = true`
* Add `context_aware` to all attribute definition resources, to create global attributes (one value shared by all contexts). Changing it on an existing definition is rejected at plan time
* Add `bluestonepim_attribute_definition_context` and `bluestonepim_attribute_group_context` to set the name (and description) of attribute definitions and groups for a specific context
### Changed
* Changing `data_type` of a `bluestonepim_attribute_definition` is now rejected at plan time instead of replacing the definition, which would remove the attribute and its values from every product. Use `terraform apply -replace` to replace it deliberately
* Attribute definitions are created with their description in a single request, instead of a create followed by a separate description update
### Fixed
* Fix import of `bluestonepim_category_attribute` (use `<category_id>/<attribute_definition_id>`), remove it from state when it no longer exists and recreate it when `category_id` or `attribute_definition_id` changes
* Remove the `text/markdown` default of `content_type` and the `text` default of `restrictions.enum.type` on `bluestonepim_attribute_definition`, which caused changes for definitions without these values. `content_type` now accepts `text/html` instead of `html`
* Keep the `value_id` of select values on `bluestonepim_attribute_definition` when values are added, removed or reordered, by matching them on `value_id` or `number` (never on the label, which doesn't have to be unique). `value_id` can now also be set explicitly
* Use the `api_url` provider setting, it was only applied when `client_secret` was set in the provider configuration
* Store an empty category description as null on `bluestonepim_category` and keep the generated `number` stable
* Update categories with a partial update instead of a full update, and no longer send an empty `number` when it is not configured
* Remove `bluestonepim_attribute_definition`, `bluestonepim_category`, `bluestonepim_context` and `bluestonepim_webhook` from the state when they were deleted outside of Terraform, instead of failing
* Deleting a `bluestonepim_category` failed because the API returns `202 Accepted` for the asynchronous delete
* Retry rate limited requests for longer (10 retries, up to 60 seconds apart, with jitter), so large plans no longer fail with `giving up after 5 attempt(s)`
### Security
* Build with Go 1.27.3, which fixes vulnerabilities in the standard library (net/http, crypto/tls, crypto/x509 and others) used by the provider, and check for known vulnerabilities with govulncheck in the test workflow
### Dependency
* Update Go and Terraform plugin dependencies
* Update Go dependencies, including bluestonepim-go-sdk
